# TMM department website – design variants (demo)

A catalog of seventeen working design concepts for a website of the **Department of Theory of Mechanisms and Machines** at the Technical University of Sofia (TU-Sofia).

**Open the catalog: https://viktornikolov038.github.io/tmm-tu-sofia-demo/**

## About this project

- These are **unofficial design prototypes**, made to compare directions (institutional, editorial, cinematic, 3D, interactive, playful) before building a real site.
- **This is not the official website of the department or the university.** The official page is at [tu-sofia.bg](https://tu-sofia.bg/bg/departments/theory-of-mechanisms-and-machines).
- Factual content (department history, head and deputy head, contacts, general description) is taken from the official page. Nothing else is invented: there are no real news items, staff lists, curricula or fees.
- Pictures marked as illustrations and the videos are **AI-generated** and do not show real facilities. The 2D/3D mechanism animations are drawn by code.
- The variants are static HTML, CSS and JavaScript, in Bulgarian and English. Some load web fonts and a few libraries (for example three.js) from public CDNs.

Each variant has a "← All variants" button to return to the catalog.
